HOW TO PUT THIS PORTFOLIO ON GITHUB (one-time setup, about 10 minutes)

The folder is already a git repository with a first commit. Nothing has been sent anywhere yet. GitHub's command-line tool (gh) is not installed on this PC, so the steps use the website plus two git commands.

1. Go to https://github.com and sign in (or create a free account).
2. Top right, press the + and choose "New repository".
   - Name: soc-investigation-portfolio
   - Description: SOC analyst training investigations (Splunk, Wireshark, phishing, Windows logs)
   - Public
   - Do NOT tick "Add a README" or ".gitignore" (this folder already has them).
   - Press "Create repository".
3. GitHub shows a page with commands. Ignore them and open PowerShell here:
   right-click inside this folder in File Explorer, "Open in Terminal".
4. Paste these two lines, replacing YOURNAME with your GitHub user name:

   git remote add origin https://github.com/YOURNAME/soc-investigation-portfolio.git
   git push -u origin main

   Git will open a browser window to sign in the first time. Approve it.
5. Refresh the GitHub page. The README is now the front page recruiters see.

ADDING A REPORT LATER
- Copy reports\TEMPLATE.md to reports\<short-name>\README.md and fill it in after you finish the investigation.
- Put screenshots in reports\<short-name>\images\.
- Add one row to the table in README.md.
- In the terminal:  git add .   then   git commit -m "Add <short-name> report"   then   git push
- Or ask Claude to do the commit and review the write-up. Claude will not write a report for an investigation you have not done.

WHAT NOT TO UPLOAD
- Raw log files, packet captures, zips (the .gitignore blocks the common ones).
- Room answers, flags, or copied room text from TryHackMe or LetsDefend.
- Anything from work.
