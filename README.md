# SOC Investigation Portfolio

Hands-on security investigation write-ups from training platforms and a personal Splunk home lab.

Every report here is a **training exercise, simulated incident, or personal lab project**. None of it comes from a real employer or real customer data. Each report says where the data came from and which tools were used.

## How each report is written

Every report follows the same template ([reports/TEMPLATE.md](reports/TEMPLATE.md)):

1. Objective and scenario
2. Tools and data sources
3. Evidence and indicators
4. Queries and commands used
5. Investigation reasoning
6. MITRE ATT&CK techniques
7. True positive or false positive, with the reason
8. Severity and escalation recommendation
9. Incident summary

Screenshots live in `reports/<report-folder>/images/`. Queries are copied exactly as run, so they can be rerun.

## Rules this portfolio keeps

- Nothing fabricated. No invented findings, screenshots, queries, or experience.
- No platform content that its terms forbid sharing (walkthrough answers, flags, copied room text). Reports describe my own investigation process and results.
- No sensitive data: no real credentials, no employer systems, no customer information.
